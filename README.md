# Contact Page – Personal Portfolio

A simple and beginner-friendly **Contact Page** built using HTML and CSS as part of my frontend web development learning journey.

## 📌 Project Overview

This project demonstrates how to create a personal portfolio contact page with a navigation link, contact form, and social media links using basic HTML and CSS.

## 🚀 Features

- **Personal Header:** Displays my name and professional role.
- **Home Navigation:** Provides a link to return to the portfolio home page.
- **Contact Form:** Includes fields for name, email, and message.
- **Submit Button:** Styled with a hover effect using CSS.
- **Social Media Links:** Includes Instagram and LinkedIn links.
- **Custom Font:** Uses the Young Serif font from Google Fonts.
- **CSS Styling:** Includes colors, padding, margins, borders, and hover effects.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
